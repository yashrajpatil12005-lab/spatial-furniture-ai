# Spatial Furniture AI

An AI-powered furniture visualization and sales assistant project.

## Current Development Phase
**Phase 1: Foundation (Day 1)**
Currently, this repository contains the foundational Next.js architecture, responsive UI components, and routing structure.

Features implemented:
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS styling (Premium, clean aesthetic)
- Customer, Retailer, and Admin route shells
- Component architecture (`src/components/layout`, `src/components/ui`)
- Firebase architecture placeholder (`src/lib/firebase`)

*Note: No actual Firebase auth, fake data, AR, Gemini AI, or Unity integrations have been implemented yet. These are reserved for future phases to keep the foundation clean and modular.*

## Getting Started

First, install dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
